# Mars IT — Образовательная платформа для студентов Mars IT School

Полнофункциональное, отзывчивое веб-приложение образовательной платформы **Mars IT**, разработанное с использованием **React + Vite**, чистого **CSS с CSS-переменными** и системы 4 тем.

---

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
cd mars-it
npm install
```

### 2. Запуск локального сервера разработки
```bash
npm run dev
```
Сервер запустится по адресу: **http://localhost:5173** (или **http://127.0.0.1:5173**).

### 3. Сборка для production
```bash
npm run build
npm run preview
```

## 🎨 Система 4 тем (`[data-theme="..."]`)

Переключение тем реализовано через CSS-переменные в `src/styles/themes.css`. Тема сохраняется в `localStorage`:

1. ☀️ **ESKI** — классический современный светлый дизайн с индиго-акцентами.
2. 🛤️ **YO'LAK** — стиль беговой дорожки с зеленой палитрой и полосатым фоном.
3. 👾 **PIXEL** — ретро 8-битный стиль: шрифт `Press Start 2P`, жесткие прямоугольные рамки (0px border-radius), четкие тени со сдвигом.
4. 🌙 **NEON** — темная тема с неоновым бирюзовым свечением (`text-shadow`, `box-shadow`) и глубоким космическим фоном.

## 📱 Страницы и разделы

1. **Главная (`/`)**
   - Блок «Ваш уровень» с интерактивной картой прогресса из 10 узлов-этапов (активный подсвечен, пройденные отмечены, будущие приглушены).
   - Список заданий со статусами («Ожидает», «Выполнено», «В процессе») и возможностью выполнения с начислением монет.
   - Промо-баннер «Mars Code» с градиентным оформлением и CTA-кнопкой.
   - Карточка прогресса курса с круговым индикатором (70%), счетчиками «93 выполнено» и «39 уроков», кнопкой «Продолжить».

2. **Мои курсы (`/courses`)**
   - Секция «Продолжить»: текущий активный курс («React.js — Профессионал») с прогрессом и переходом к уроку.
   - Секция «Бесплатные курсы»: сетка из 6 бесплатных курсов (HTML/CSS, JS, Python, Git, SQL, Linux) с метаданными и кнопками «Начать».

3. **Мои работы (`/works`)**
   - Вкладки: «Мои работы», «Портфолио», «Весь план», «Файлы», «Мой диск».
   - Индикатор прогресса курса (33/132 заданий выполнено).
   - Группировка заданий по статусам:
     - *«Вернули на доработку»*
     - *«На проверке»*
     - У каждого элемента: номер ДЗ, название, ссылка на GitHub, дата и кнопка «К уроку».

4. **Battle (`/battle`)**
   - Вкладки: **BATTLE**, **РЕЙТИНГ**, **СОПЕРНИКИ**, **ЭМОЦИИ**.
   - Статистика: молнии (⚡), стрик дней (🔥), победы (🏆).
   - Арена «Вы VS Выбрать» с аватарами участников.
   - Кнопка «Найти соперника» (анимация поиска и подбор противника).
   - Режим «Тренировка с ботом» (интерактивный квиз против Mars Bot с мгновенной проверкой ответов, начислением монет и молний).
   - Лидерборд с рангами, золотыми/серебряными медалями.
   - Список онлайн-соперников с кнопкой «Вызвать».
   - Сетка боевых реакций-эмодзи.

5. **Хакатон (`/hackathon`)**
   - Вкладки: **Главная**, **Подготовка**, **Моя команда**, **Команды**, **Темы**, **Сдача работы**, **Галерея**, **Результаты**.
   - Обратный отсчет до старта «Mars Hack 2026».
   - Раздел «Что нужно сделать» с 3 шагами:
     1. *Собрать команду*
     2. *Выбрать тему*
     3. *Сдать работу*
   - Интерактивный выбор темы, форма сдачи проекта со ссылками на репозиторий и деплой.

6. **Эдуверс (`/eduvers`)**
   - Автономный лендинг с собственным компактным хедером.
   - Выбор возрастных категорий с большими карточками: **«7–11 лет»** и **«12–17 лет»**.
   - Переключатель языка **RU / UZ** с мгновенным изменением всех текстов.
   - Кнопка быстрого возврата в кабинет Mars IT.

7. **Профиль (`/profile`)**
   - Карточка студента с аватаром, именем, группой и счетчиками.
   - Возможность забрать ежедневный бонус (+монеты, +молнии).
   - Форма редактирования личных данных (имя, email, телефон, био) с сохранением в `AuthContext` и `localStorage`.

8. **Глобальные элементы**
   - **Top Bar**: баланс, стрик дней (🔥), монеты (🪙), молнии (⚡), кнопка «👑 Premium», переключатель темы, колокольчик уведомлений с бейджем и выпадающим списком, профильный дропдаун.
   - **Left Sidebar**: навигация (Главная, Мои курсы, Мои работы, Battle, Хакатон, Эдуверс) + оригинальный авторский SVG-маскот робота/космонавта Mars Bot.
   - **AI Assistant**: плавающий виджет робота в правом нижнем углу с чатом, индикатором набора текста и ответами на вопросы.
   - **Mobile адаптивность**: корректно работает на экранах от 360px, навигация превращается в нижний бар (Bottom Navigation Bar) и гамбургер-меню, плавающие кнопки и шапка адаптируются.
